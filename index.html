El Problema y la Solución

Consumo Ineficiente

En México, el sector residencial consume el 14.4% de la energía nacional. El "consumo fantasma" representa hasta un 15% del desperdicio.

Nuestra Propuesta

MyVolt utiliza IA y un dispositivo IoT para convertir tu recibo en un plan de ahorro medible, buscando reducir hasta un 20% tu gasto.

Arquitectura Propuesta

Machine Learning

Implementación de Isolation Forest para anomalías y Prophet para pronóstico de consumo.

Backend y Datos

Desarrollado con Java 17, FastAPI y PostgreSQL para una gestión de datos robusta.

Funciones del Ecosistema

Historial y Gráficas

Gamificación

Retos y recompensas personalizadas para motivar la adquisición de hábitos sostenibles.

Funciones Premium (IA)
